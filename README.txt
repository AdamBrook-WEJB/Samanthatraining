SAMANTHA'S TRAINING PLAN
========================
index.html is the whole app — nothing else needed.

TO JUST USE IT (easiest)
  Open index.html on the phone and add it to the home screen. It then works like an app.

TO PUT IT ONLINE (GitHub Pages)
  1. Make a new repository on github.com.
  2. Upload index.html to it (keep the name exactly as it is).
  3. Repo Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)".
  4. A minute later the link is https://<your-username>.github.io/<repo-name>/

NOTES
  The plan, journal and water tracker save in whichever browser it is opened in.
  There is a Save a backup / Restore option under Journal > Sharing & backup.
  A summary emails to Adam each time a session is saved. That can be switched off
  in the same place.
